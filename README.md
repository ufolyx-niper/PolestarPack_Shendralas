# Polestar 辛德拉指南

《魔兽世界：无限》辛德拉（Shen'dralas）的简体中文任务指南。需要先安装 [Polestar Guides](https://www.curseforge.com/wow/addons/polestar) 0.3.7.2 或更新版本。

- 野外主线建议 38–45 级，包含水晶塔、神殿、花园和可跳过的武器及精英任务。
- 吉尔吉斯和马格拉姆分别有一条支线，可按角色已支持的部族选择。
- 玛拉顿与剃刀高地专项从水晶塔前置开始，包含取水、灭火和采血。

## 用 WowUp 安装和更新

1. 在 WowUp 顶部选择 **WoW Forever**。
2. 打开 **Get Addons → Install from URL**，粘贴本仓库地址 `https://github.com/ufolyx-niper/PolestarPack_Shendralas`。
3. 安装后可在 **My Addons** 中右键插件，开启 **Auto Update**。
4. 进游戏输入 `/polestar guides`，搜索「辛德拉」。

也可以从 [Releases](https://github.com/ufolyx-niper/PolestarPack_Shendralas/releases/latest) 下载以 `-forever.zip` 结尾的附件，解压到 Forever 客户端的 `Interface/AddOns`。

任务前置、坐标来源和已知限制见 [包内说明](PolestarPack_Shendralas/SOURCES.txt)。0.1.0 已通过离线验证，部分半人马任务能否接取以游戏内 NPC 实际提供为准。
